## 规划重点

地图按活动打卡、地铁、交易广场、街拍、咖啡厅、风险路段分类。点击卡片可在 Google Maps 查看位置及调用步行导航。网页采用 OpenStreetMap 地图底图及公开地名检索服务，网络不可用时可直接使用卡片导航链接。

### 核心路线

1. 17:00 交易广场集合 → 皇后像广场南花园（官方装置）。
2. 18:00 砵典乍街石板街拍照。
3. 18:40 德己立街、兰桂坊主街看万圣节 Cosplay。
4. 19:30 后视人流转到 SoHo 士丹顿街、卑利街，或返回中环地铁站。

### 地铁/交通

- 香港站：IFC / 交易广场方向；可通过行人天桥及地下步行网络转往中环。
- 中环站 K：皇后像广场。
- 中环站 D2：兰桂坊、砵典乍街方向（万圣节夜受现场控制）。

### 咖啡厅

Café Claudel、Café Landmark、Milligram Coffee、Coffeelin、Haus Coffee Club。**未确认万圣节晚间营业时间**。

### 注意

和安里、荣华里位于或紧邻核心活动区，不宜作为绕过人流管制的捷径；石板街也可能是排队缓冲区。晚间交通按当日警务处公告与路面人员指引。
